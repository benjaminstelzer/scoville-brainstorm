# Changelog

## v1.1.7 - 2026-09-11

- Return control to the ordinary task after a negative activation decision. Reading the Core for an audit does not activate Brainstorm; reuse that read if a later decision activates it.
- Behavioral acceptance remains deferred. This release adds no live-model or cross-host qualification.

## v1.1.5 - 2026-09-09

- Respect observable task capacity when optional cleanup controls are missing.
- Keep status questions inside the active run and report material blockers
  immediately.

## v1.1.3 - 2026-09-05

- Added bounded source recovery before freezing the problem frame.
- Stop when a known material change invalidates the frozen frame instead of
  continuing with stale assumptions.
- Keep observations separate from fixed constraints and preserve exact source
  IDs and user constraints.

## v1.1.0 - 2026-08-19

- Added combined operation with Scoville Research as the sole prior-art
  landscape owner.
- Keep generators isolated from landscape and sibling output until their own
  proposals converge.
- Added source-origin collapse, private-query sanitization, prompt-injection
  handling, and calibrated originality language for the Research lane.

## v1.0.1 - 2026-08-11

- Made every Scoville Skill optional and independently usable. Discovering a
  sibling does not install or activate it.

## v1.0.0 - 2026-08-11

- Added decision-shaped exploration before implementation or durable planning.
- Added isolated generation, bounded prior-art comparison, mechanism
  clustering, independent criticism, constraint checks, and an explicit stop
  before choosing a direction.
- Added Compact, Standard, and Deep effort profiles with a single-coordinator
  fallback when fresh tasks are unavailable.
